# Agentic SDLC: Building a Software Factory

This course teaches you to build a suite of Kiro CLI agents that automate each phase of the software development lifecycle. Working through six modules, you will create agents for Git workflow management, software architecture (arc42/C4), requirements engineering (user stories/DDD), CI/CD pipelines (GitHub Actions/SAM), and TDD/BDD test automation, then combine them into a final project. By the end, you will have a personal AI-powered software factory capable of driving an entire SDLC from a single prompt.
